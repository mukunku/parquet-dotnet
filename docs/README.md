# Parquet.Net

This is my personal fork of [Parquet.Net](https://www.nuget.org/packages/Parquet.Net), originally developed at `aloneguid/parquet-dotnet` which no longer exists. 

I mainly maintain this fork to support my other project, [ParquetViewer](https://github.com/mukunku/ParquetViewer), until I decide whether to keep using this library or switch to another one.

👉 Original [home + documentation](https://www.aloneguid.uk/projects/parquet-dotnet/) 👈

## Recovered issues

The original repository's issues were lost when it was deleted. I recovered what I could of its 259 issues from [GH Archive](https://www.gharchive.org/), the public record of GitHub events, and saved them in the [issues](https://github.com/mukunku/parquet-dotnet/tree/main/issues) folder, one file per issue.

The [issue list](https://github.com/mukunku/parquet-dotnet/blob/main/issues/README.md) shows how much of each issue survived and which ones have been fixed in this fork.
