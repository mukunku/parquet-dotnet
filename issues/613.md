### Issue description

Hello,

I need to deserialize a parquet file without having control of the generation of this parquet.

![Image](https://github.com/user-attachments/assets/a9843a56-d166-4745-9de6-a58ea28a5fe4)

The problem is that the first struct is defined as "REQUIRED" and the "DL" is equal to 0.  But when the schema is build using the library the "DL" is set to 1 because the class is Nullable event if not declared as nullable in the C# class.

```c#
public class Model 
{
    [JsonPropertyName("modelPropertyOne ")]
    public string ModelPropertyOne { get; set; } = string.Empty;

    [JsonPropertyName("entry ")]
    public Record Entry { get; set; } = new();
}

public class Record 
{
    [JsonPropertyName("recordPropertyOne ")]
    public string RecordPropertyOne { get; set; } = string.Empty;
}
```
When debugging using the library, I seen the following schema.

| Property | DL |
| --------- | ------------- |
| ModelPropertyOne | 0 |
| Entry | 1 |
| RecordPropertyOne | 1 |

This schema doesn't match the schema defined in the parquet file.

Did some testing and modification to allow the "ParquetRequired" attribute on the struct to work and allow the deserialization.

Is there another way to allow the deserialization?
