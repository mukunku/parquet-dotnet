# #331: [BUG]: cannot count nulls in type System.Nullable`1[System.Guid]

- **State:** closed (closed 2023-05-16)
- **Author:** MarkoPielic
- **Created:** 2023-05-16
- **Original URL:** https://github.com/aloneguid/parquet-dotnet/issues/331
- **Recovery status:** Recovered

## Description

### Library Version

4.11.1

### OS

Windows 10

### OS Architecture

64 bit

### How to reproduce?

Try to add column of type Guid? and store it in the parquet file.

### Failing test

```csharp
using Parquet;
using Parquet.Data;
using Parquet.Schema;

List<Guid?> data = new List<Guid?>() { Guid.NewGuid(), null, Guid.Empty, Guid.NewGuid() };

List<DataField> dataFields = new List<DataField>();
dataFields.Add(new DataField<Guid?>("nullable_guid"));

var schema = new ParquetSchema(dataFields);
using (var ms = new FileStream("out.parquet", FileMode.Create))
{
    using (ParquetWriter parquetWriter = await ParquetWriter.CreateAsync(schema, ms))
    {
        using (ParquetRowGroupWriter groupWriter = parquetWriter.CreateRowGroup())
        {
            await groupWriter.WriteColumnAsync(new DataColumn(dataFields[0], data.ToArray()));
        }
    }
}
```
