## Comments

### pavlexander on 2023-09-25

**Update!** On the second day I am no longer seeing any exceptions - the whole program simply freezes on the data load step..

I started experimenting and managed to make the loading work in a clean Console app. It looks like the problem was that I was using the WinForms app. After further investigation I also manged to fix the WinForms app. See the code below.

this does not work

```csharp
        private void button2_Click(object sender, EventArgs e)
        {
            var dataParquet = ObjectExtensions.LoadFromParquet(parquetFullPath).Result.ToList();
        }
```

this works

```csharp
        private async void button2_Click(object sender, EventArgs e)
        {
            var dataParquet = (await ObjectExtensions.LoadFromParquet(parquetFullPath)).ToList();
        }
```

I am not sure what the original problem was. I can no longer trigger the exception throwing..
If there are any suggestions on how to handle the file loading in winforms please reply. If not - feel free to close the bug.
