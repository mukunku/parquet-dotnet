## Description

### Issue description

The old way of serialization was to use ParquetColumn attributes.  With these attributes, you could specify the storage format for dates and times or the precision and scale for decimals.

The new way if serialization is to use Json attributes. How can you specify these additional settings?

## Comments

The new serializer does not support this feature yet, but I'm working on it and it will be available soon. In the meantime, you can use the old serializer or the low level api to customize your output. I'll update you here when the feature is ready.
