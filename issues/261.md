## Description

Hey,
I tried to use Spark 3.2 to read parquet files written using Parquet.Net. The Spark job took very long, so I looked into Spark logs and saw this:

**Ignoring statistics because created_by could not be parsed (see PARQUET-251): Parquet.Net v4.4.6
org.apache.parquet.VersionParser$VersionParseException: Could not parse created_by: Parquet.Net v4.4.6 using format: (.*?)\s+version\s*(?:([^(]*?)\s*(?:\(\s*build\s*([^)]*?)\s*\))?)?**

Any idea what is this "created_by", and how can it be changed?

Thanks!

### aloneguid on 2023-02-14

Yeah this is weird. From thrift spec:

```
  /** String for application that wrote this file.  This should be in the format
   * <Application> version <App Version> (build <App Build Hash>).
   * e.g. impala version 1.0 (build 6cf94d29b2b7115df4de2c06e2ab4326d721eb55)
   **/
  6: optional string created_by
```

key words are "should" and "optional".
