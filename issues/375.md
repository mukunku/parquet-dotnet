## Description

As of now, parquet.net does not support delta encoding.


https://github.com/aloneguid/parquet-dotnet/issues/205 Parquet.net already supports read, however write is currently not supported.

Delta Binary Packed encoding is designed to achieve high compression ratios for numerical data types. 
It efficiently packs the numerical values, reducing the amount of storage required to store the data on disk. 
This can result in significant storage space savings, especially for datasets with large numeric columns.
