### tylerchessman on 2023-04-18

Just an update for anyone else who may come across this issue:  I was able to get things working; DateTime data type does need to be switched to DateTimeOffset (when creating the DataField object) - but I had to modify the sample datatable-to-parquet sample code to something like - 
{ await rgw.WriteColumnAsync(new Parquet.Data.DataColumn(fields[i], dt.AsEnumerable().Skip(startRow).Take(RowGroupSize).Select(s => s.Field<DateTime?>(dt.Columns[i].ColumnName)).ToArray<DateTime?>())); }

Interestingly, if you are pulling in a DataTimeOffest from the database, it also requires a DateTimeOffset (when creating the DataField object) - but I had to convert the actual row _values_ to a DateTime prior to writing the column.
