## Description

**Library Version:** latest: 4.2.3
**.NET Version:** .NET 6
**OS:** Windows 10

#### Expected Behaviour
ParquetConvert.DeserializeAsync will not throw an Exception System.ArgumentOutOfRangeException for null DateTime under specific conditions


#### Actual Behaviour
ParquetConvert.DeserializeAsync throws Exception System.ArgumentOutOfRangeException for null DateTime under specific conditions

#### Code Snippet to reproduce 

```csharp

// test steps.
var data = Enumerable.Range(0, 10000).Select(i => new Data { Id = i, DateTime = DateTime.Now }).ToList();

foreach (var item in data.Take(7000))
{
    item.DateTime = null;
}

var stream = new MemoryStream();

var schema = await ParquetConvert.SerializeAsync(data, stream);

try
{
    var result = await ParquetConvert.DeserializeAsync<Data>(stream);
}
catch (Exception e)
{
    var res = JsonConvert.SerializeObject(e);
    Console.WriteLine(e);
    throw;
}
```
