## Description

### Library Version

4.5.4

### OS

Windows 10 / Ubuntu 22.04

### OS Architecture

64 bit

### How to reproduce?

Say you have an array of some value type (`bool`, `int`, etc.), but it does **not** contain any nullable values. If you pass that array to a `DataColumn` along with a `DataField` instance created with `isNullable = false`, you will get an exception when you try to write it with `WriteColumnAsync`. Passing `isNullable = true` seems to work fine. For reference types (string), either value will work. I'm not sure what the "right" thing to do between these two is:

- Pass a more informative error message to the user. Right now you don't get a more informative exception message than: `System.IO.IOException : failed to encode data page data for column <...>`. This is quite confusing, since it doesn't give any hint that nullability is the problem, and you wouldn't suspect that's the issue if your data doesn't have any nulls in it.
- Give priority to the `isNullable` option over the type of the array, and only fail if you detect a null value in the passed array. This is consistent with the reference type behavior, and it's a bit more ergonomic, since you may not realize you have a nullable type array on your hands.

I think the second option is better, but I'm not sure if there are barriers to implementation. I could give it a try, if it's not trivially fixable by you.

### Failing test

```csharp
public class ParquetTests
{
    [Theory]
    [InlineData(true)] // Succeeds, as you'd expect
    [InlineData(false)] // Fails, without an informative error message. You may also expect this not to fail, since no nulls exist in the array
    public async Task CanWriteNullableBoolArrayWithoutNulls(bool explicitlyNullable)
    {
        using var stream = new MemoryStream();
        var boolCol = new DataColumn(new DataField("someBool", typeof(bool), explicitlyNullable), Enumerable.Repeat(true, 5).Cast<bool?>().ToArray());
        var schema = new ParquetSchema(new[] { boolCol.Field });
        using var writer = await ParquetWriter.CreateAsync(schema, stream);
        using var rowGroupWriter = writer.CreateRowGroup();
        await rowGroupWriter.WriteColumnAsync(boolCol);
    }

    [Theory]
    [InlineData(true)] 
    [InlineData(false)]
    // Both options will pass here, as you'd expect
    public async Task CanWriteNullableStringArrayWithoutNulls(bool explicitlyNullable)
    {
        using var stream = new MemoryStream();
        var strCol = new DataColumn(new DataField("someStr", typeof(string), explicitlyNullable), Enumerable.Repeat("foo", 5).Cast<string?>().ToArray());
        var schema = new ParquetSchema(new[] { strCol.Field });
        using var writer = await ParquetWriter.CreateAsync(schema, stream);
        using var rowGroupWriter = writer.CreateRowGroup();
        await rowGroupWriter.WriteColumnAsync(strCol);
    }
}
```
