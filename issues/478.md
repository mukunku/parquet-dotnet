### Issue description

If I write a parquet file in python using the legacy int96 timestamps:
```pq.write_table(tbl, path, use_deprecated_int96_timestamps=True)```
Then parquet.net can detect the DateTime format:
![image](https://github.com/aloneguid/parquet-dotnet/assets/90620964/9e2c9e6c-6037-4478-a021-07b9b6ba77f0)

However if I do ```use_deprecated_int96_timestamps=False```,
then the low-level api is not able to detect the type, instead it detects it as int64 type:
![image](https://github.com/aloneguid/parquet-dotnet/assets/90620964/720b3fdf-74c2-4904-a9ee-b3069ae48f94)

So is there a way to deserialise the new timestamp format with low-level api?
