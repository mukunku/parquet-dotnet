### aloneguid on 2024-03-07

Current workaround is to mark enum properties with `JsonIgnore` and expose supported properties as you want for serialization. For example:

```csharp
class A {
  [JsonIgnore]
  public MyEnum B { get; set; }

  [JsonPropertyName("B")]
  public string B_ {
    get => B.ToString(); // or int, or whatever you want
    set { B = Enum.Parse... }
  }
}
```
