## Comments

### aloneguid on 2024-12-03

I think you have a bug here (Program.cs, line 166):

```csharp
await using FileStream fStream = aDestination.OpenWrite();
```

This opens existing file and writes data on top, so you get dirty file consisting of previous + new data. If you delete the file before writing it seems to be just fine.

### alex-g-axion on 2024-12-12

Thank you!  Looks like this is the cause.  I cannot reproduce the issue after using `Open(FileMode.Create)` instead of `OpenWrite()`  .
