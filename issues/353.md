### aloneguid on 2023-06-20

There is physically no option to sample rows n **any** library, this is how parquet format works. The data is stored in columns, not rows.

For instance, in row-based formats, like CSV, in order to sample a column you would need to read all rows. In parquet, being column-based, the reverse applies.

You can, however, read a *column chunk*, but only if data was written in chunks in the file itself:

```csharp
using(Stream fs = System.IO.File.OpenRead("/mnt/storage/data.parquet")) {
    using(ParquetReader reader = await ParquetReader.CreateAsync(fs)) {
          // open the first row group (0) - reads the first chunk
          using(ParquetRowGroupReader rowGroupReader = reader.OpenRowGroupReader(0)) {

                  DataColumn columnData = await rowGroupReader.ReadColumnAsync(/* column */);

          }
    }
}
