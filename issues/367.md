## Description

### Issue description

I would like the ability to create a DataColumn using this signature:
`public DataColumn(..., Array data, int startIndex, int length) { ... }`
where the 2 params `startIndex` and `length` are added to indicate the slice of `data` to actually write.

This would allow the use of fixed length buffers and avoid unnecessary array allocations.

For instance, for the use case of writing row groups (column chunks) of size N, I would allocate arrays of length N. But the total number of rows is not a multiple of N, the last row group with size <N which means another array allocation.

Please advise if I am missing something obvious here.
