### nullfx on 2025-01-09

I know this is a super old issue (and closed) but...  the library does reference System.Memory v4.0.1.2 which references System.Buffers v4.0.3 and parquet.net references System.Buffers v4.0.2 and thus (under certain conditions like one we're seeing) has an unhanded exception trying to locate system.buffers v4.0.2 causing us to roll our own version of this library.

you need to update system.buffers to the latest version IMHO.
