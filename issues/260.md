# #260: ParquetConvert.SerializeAsync with "append: true" doesn't work

## Description

Similar to #152, but for the async version `ParquetConvert.SerializeAsync(IEnumerable<T> objectInstances, string filePath, ...)`.

Seen in
Parquet.Net 4.4.7
.NET 6
Windows

If appending to a file with `ParquetConvert.SerializeAsync()` with the `append` parameter set to true, an `System.IO.IOException` will be thrown with message 'only 0 out of 4 bytes are available'. The workaround is to open a stream from the file manually and use the stream version of  `ParquetConvert.SerializeAsync()`.

Code to reproduce

```csharp
using Parquet;

var data = new[] { new { Integer = 1 } };

// Throws System.IO.IOException: 'only 0 out of 4 bytes are available'
string fileName = @"Fail.parquet";
await ParquetConvert.SerializeAsync(data, fileName);
await ParquetConvert.SerializeAsync(data, fileName, append: true);

// Succeeds
using var stream = File.Open(@"Succeed.parquet", FileMode.OpenOrCreate);
await ParquetConvert.SerializeAsync(data, stream);
await ParquetConvert.SerializeAsync(data, stream, append: true);
```
