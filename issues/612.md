# #612: [BUG]: Serialising a list of lists fails

- **State:** open
- **Author:** Vannevelj
- **Created:** 2025-04-17
- **Original URL:** https://github.com/aloneguid/parquet-dotnet/issues/612
- **Recovery status:** Recovered

## Description

### Library Version

5.1.1

### OS

MacOS

### OS Architecture

ARM 64

### How to reproduce?

```cs
using Parquet.Serialization;

var obj = new Root([[3.2]]);
await ParquetSerializer.SerializeAsync([obj], new MemoryStream());

public record Root(List<List<double?>> Values);
```

It appears that as soon as you have a List of Lists, the serialisation fails. In this case it fails with stacktrace
