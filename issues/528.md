### EamonHetherton on 2024-07-10

The error suggests that the "data" being passed to the ParquetDictionaryEncoder contains null values.  Due to the fact that a HashSet<string> allows you to add a null, but a Dictionary<string,int> does not accept null as a key when it calculates the value to index mapping in ParquetDictionaryEncoder the exception is generated but probably shouldn't even be getting to here with nulls in the first place.  Will need to know the shape and contents of the objects you are trying to serialise to investigate this further.
