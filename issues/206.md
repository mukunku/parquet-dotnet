### aloneguid on 2022-12-15

@mithom you can write file level metadata (`writer.CustomMetadata` member) but not column wise at the moment. The reason is only it wasn't useful so far. You're welcome to add it.

Regarding classic .NET - it's not compatible even with .net standard 2.1 so it's a lot of effort to support by myself, especially when moving to async and memory spans to improve performance. It would essentially mean supporting two different codebases.
