### How to reproduce?

Hello! I am actually not 100% sure if this is a bug or something I am doing wrong, but please help!

Have a complex table structure like following:

```
        var t = new Table(
            new DataField<int>("prop1"),
            new StructField("propx",
                new DataField<int>("prop2"),
                new ListField("list2",
                    new StructField("element",
                        new DataField<int>("prop3")
                    )
                )
            ),
            new ListField("list1",
                new StructField("element",
                    new DataField<int>("prop2"),
                    new ListField("list2",
                        new StructField("element",
                            new DataField<int>("prop3")
                        )
                    )
                )
            )
        );
```

The following data saves to a parquet file, and the file can be opened.

```
        for (var i = 0; i < 10; i++)
        {
            t.Add(
                i,
                new Row(
                    i,
                    new[]
                    {
                        new Row(i)
                    }
                ),
                new[]
                {
                    new Row(
                        i,
                        new[]
                        {
                            new Row(i),
                            new Row(i),
                            new Row(i)
                        }
                    )
                });
        }

        await t.WriteAsync("simplearray.parquet");
```

THe following data saves to a parquet file, but cannot be opened

Notice two more `new Row(i)` in the first list of struct.

```
        for (var i = 0; i < 10; i++)
```
