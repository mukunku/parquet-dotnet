## Description

### Issue description

The Row class supports three possible types: IEnumerable<object>, object, and object?[]. If the schema contains optional fields, then only the object?[] type is suitable, not IEnumerable<object>. Therefore, it is necessary to convert IEnumerable<object> to an array to ensure compatibility with optional fields in the schema.
