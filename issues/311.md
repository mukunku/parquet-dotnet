## Description

### Library Version

v4.9.1

### OS

Windows

### OS Architecture

64 bit

### How to reproduce?

Starting with [v4.8.0](https://github.com/aloneguid/parquet-dotnet/releases/tag/4.8.0) when reading some map fields the `Data` property of the DataColumn is returned as an empty array. Is this behavior change by design?

_Not sure but maybe related to #303_ 

### Failing test
Run the following code [on this file](https://github.com/aloneguid/parquet-dotnet/files/11300320/MAP_FIELD.zip) that contains a map field. v4.7.1 works but v4.8.0+ fails.
```csharp
using var reader = await ParquetReader.CreateAsync("MAP_FIELD.parquet");
var keyField = reader.Schema.GetDataFields().Where(df => df.Path.ToString() == "col1/key_value/key").First();
var valueField = reader.Schema.GetDataFields().Where(df => df.Path.ToString() == "col1/key_value/value").First();

using var groupReader = reader.OpenRowGroupReader(0);
var keys = await groupReader.ReadColumnAsync(keyField);
var values = await groupReader.ReadColumnAsync(valueField);

if (values.Data.Length != keys.Data.Length)
    Console.WriteLine("Data count doesn't match");
else
    Console.WriteLine("Success");
```
