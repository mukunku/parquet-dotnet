## Description

### Issue description

According to the [documentation](https://aloneguid.github.io/parquet-dotnet/encodings.html), dictionary encoding should be enabled by setting `UseDictionaryEncoding = true`. However, I’m unable to get it to work as expected.

### Steps to Reproduce

If I grab the existing test case from [`DictionaryEncodingTest.cs`](https://github.com/aloneguid/parquet-dotnet/blob/202f421abfa17a19e4d3c1cb7e05c316e973326c/src/Parquet.Test/DictionaryEncodingTest.cs) and write the results to a file:

```csharp
using Parquet;
using Parquet.Data;
using Parquet.Schema;

string?[] data = new string?[]
{
    "xxx",
    "xxx",
    "xxx",
    "xxx",
    "xxx",
    null,
    "yyy",
    "yyy",
    "yyy",
    string.Empty,
    "yyy",
    "yyy",
    null,
    null,
    "zzz",
    "zzz",
    "zzz",
    "zzz",
};

var dataField = new DataField<string>("string");
var parquetSchema = new ParquetSchema(dataField);

using var stream = File.OpenWrite("dictionary_encoded_from_test.parquet");

using (ParquetWriter parquetWriter = await ParquetWriter.CreateAsync(parquetSchema, stream,
           formatOptions: new ParquetOptions() { UseDictionaryEncoding = true }))
{
    using ParquetRowGroupWriter groupWriter = parquetWriter.CreateRowGroup();
    await groupWriter.WriteColumnAsync(new DataColumn(dataField, data));
    await parquetWriter.DisposeAsync();
}
```

### Observed Behavior
Running `pqrs schema dictionary_encoded_from_test.parquet --detailed` shows:
```
encodings: RLE BIT_PACKED PLAIN
dictionary page offset: N/A
```
So no dictionary page is present, and RLE_DICTIONARY encoding is not used.

### Expected Behavior
```
encodings: PLAIN RLE RLE_DICTIONARY
dictionary page offset: <some offset>
```

### Environment
Library version: 5.1.1
.NET version: 9.0.301
