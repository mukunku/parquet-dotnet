# #345: Json Attribute usage breaks several use cases

- **State:** closed (closed 2023-06-29)

## Description

Hi,
The removal of distinction between Json attributes and parquet attributes is breaking use cases where an object is first deserialized from Json, and then is serialized to parquet (or various combinations of that). 
If you require different behaviors (For example deserializing a value from Json, but ignoring when serializing to parquet) this makes implementation more cumbersome,  and in my opinion Json and Parquet attributes should not be forced to correlate.
