## Description

`ParquetConvert.Deserialize` create its own `ParquetReader` instance. But for some specific parquet files, we need to pass a specific option for the reading to succeed (`TreatByteArrayAsString = true` for example).

It could be interesting to either let the user give its own `ParquerReader` or to allow passing a `ParquetOptions`.
