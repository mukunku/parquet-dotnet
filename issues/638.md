# #638: [BUG]: `DivideByZeroException` when reading boolean columns in Parquet.Net 5.x (RLE decoding bug)

- **State:** open
- **Author:** AnnaKarpf
- **Created:** 2025-08-12
- **Original URL:** https://github.com/aloneguid/parquet-dotnet/issues/638
- **Recovery status:** Recovered

## Description

### Library Version

5.1.0

### OS

Windows and Mac

### OS Architecture

32 bit

### How to reproduce?

**Description:**
When reading Parquet files with boolean columns using Parquet.Net version 5.x (tested on 5.1.0 and 5.1.1), attempting to read boolean fields with `ReadColumnAsync` causes a `DivideByZeroException` inside the RLE bit-packed decoder.


**Stack trace snippet:**

```
Error reading file: Attempted to divide by zero.
Stack trace:    at Parquet.Encodings.BitPackedEncoder.Decode8ValuesLE(Span1 src, Span1 dest, Int32 bitWidth)
   at Parquet.Encodings.RleBitpackedHybridEncoder.DecodeBitpacked(Int32 header, Span1 data, Int32& dataOffset, Int32 bitWidth, Span1 dest, Int32 maxItems)
   at Parquet.Encodings.RleBitpackedHybridEncoder.Decode(Span1 data, Int32 bitWidth, Span1 dest, Int32 pageSize)
   at Parquet.Encodings.RleBitpackedHybridEncoder.Decode(Span1 s, Int32 bitWidth, Nullable1 spanLength, Int32& usedSpanLength, Span1 dest, Int32 pageSize)
   at Parquet.File.DataColumnReader.ReadColumn(Span1 src, Encoding encoding, Int64 totalValuesInChunk, Int32 totalValuesInPage, PackedColumn pc)
   at Parquet.File.DataColumnReader.ReadDataPageV2Async(PageHeader ph, PackedColumn pc, Int64 maxValues)
   at Parquet.File.DataColumnReader.ReadAsync(CancellationToken cancellationToken)
   at Program.Main() in ParquetReader/Program.cs:line 25
```



**Additional notes:**

* This issue prevents safe reading of boolean fields in Parquet.Net 5.x.
* Workarounds such as reading boolean columns as `byte[]` by substituting schema fields do not work because Parquet.Net requires schema fields to be the exact instances loaded from the file.
* The bug appears related to how RLE bit-packed boolean data pages are decoded and likely involves a zero bit-width or length parameter in the decoder.

**Request:**
Please investigate and fix the boolean RLE decoding to avoid divide-by-zero exceptions, or expose a supported API for safely reading boolean columns. This bug blocks using Parquet.Net 5.x with boolean fields in production.
