# #268: Serialization is loosing properties form base class of base class

## Description

If class hierarhy has more than one level of inheritance ParquetConvert.SerializeAsync is loosing properties form base class of base class even SchemaReflector.ReflectWithInheritedProperties is used.

Issue is caused by th fact that SchemaReflector is getting properties only form the base class instead of whole hierarchy.
PropertyHelpers.GetDeclaredPropertyFromClassType() method also requires correction.
