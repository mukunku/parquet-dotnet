## Description

### Issue description

Most serialization libraries support a concept of converters. For example, the `[JsonConverter(...)]` attribute in most JSON serialization libraries like `Newtonsoft.Json`.

I am using the `Vogen` package, which source generates immutable value types. For example, this code:
```csharp
private record class TestEntityToSerialize
{
    /// <summary>
    /// Test String.
    /// </summary>
    public string? TestString { get; set; }

    /// <summary>
    /// Test Guid.
    /// </summary>
    public Guid TestGuid { get; set; }
}
```
becomes
```csharp
private record class TestEntityToSerialize
{
    /// <summary>
    /// Test String.
    /// </summary>
    public string? TestString { get; set; }

    /// <summary>
    /// Test Guid.
    /// </summary>
    public MyIdWrapper TestGuid { get; set; }
}
```
where `MyIdWrapper` is the wrapper which effectively looks like this:
```csharp
public struct MyIdWrapper
{
    public Guid Value { get; }
    /// Initialization Code
}
```

Ideally, I could decorate my type with an attribute indicating a converter that will properly deserialize the object.

Are there any options?
