### Issue description

@aloneguid thanks for creating this useful library. Please advise about this:

OS: OS X 14.5 Env: .NET8 Parquet.Net Version: 4.24.0

I'm trying to serialize a List class containing six strings with this schema: https://github.com/xeonfusion/VSCaptureMP/blob/12321896f8beec85b271fd20430e703f83d89723/Class3.cs#L159

The List is populated by converting serial port byte arrays (through multiple read events) into strings. The List data needs to be written in multiple batches, each time the serial port receives data, into a single Parquet export file. 

This works without issues using the inbuilt .NET JSON serializer https://github.com/xeonfusion/VSCaptureMP/blob/12321896f8beec85b271fd20430e703f83d89723/Class3.cs#L2106.

But using the same populated List with the ParquetSerializer.SerializeAsync method (with Append option true) throws a FileNotFound exception:

I followed the recommended method to append data: https://aloneguid.github.io/parquet-dotnet/serialisation.html#appending-to-files

I have tried changing the FileStream FileMode to FileMode.Append (instead of FileMode.Open that is used in ParquetSerializer.cs) but it still throws an exception:

``` c#
if (NumericValList.Count != 0)
            {
                if (m_parquetappendflag == false) //flag set to false for first data batch
                {
                    await ParquetSerializer.SerializeAsync(NumericValList, pathparquet); //This works but overwrites data
                }
                else
                {
                    using (FileStream _FileStream = new FileStream(pathparquet, FileMode.Append, FileAccess.ReadWrite))
                    {
                        await ParquetSerializer.SerializeAsync(NumericValList, _FileStream, new ParquetSerializerOptions { Append = true });

                    }
                }
            }
``` 

If the library implements a concurrent queue internally for writing data batches, the Append flag option in ParquetSerializerOptions (that causes issues) probably may not be needed.

How do I append a continuously updated List to a single Parquet file, updating the records each time, without file access errors?
