## Description

### Library Version

5.1.0

### OS

Linux

### OS Architecture

64 bit

### How to reproduce?

1. Use Parquet.Net in a persistent app/service. The persistent part is important because of the caching in `GetAssembler` [here](https://github.com/aloneguid/parquet-dotnet/blob/master/src/Parquet/Serialization/ParquetSerializer.cs#L478-L481).
2. For the simplest example, prepare 2 parquet files where both files:
    - Have one column of the same name (ex: `example_column`)
    - Populate that column with a `Struct`, **but use different schemas within that `Struct`**
3. Use `DeserializeAllAsync` (untyped) to read one file and then the other
4. Get some error that looks roughly like:

I've debugged this locally and it appears that the issue is due to [how IEquatable](https://github.com/aloneguid/parquet-dotnet/blob/master/src/Parquet/Schema/ParquetSchema.cs#L225-L251) is implemented for `ParquetSchema`. [Equals](https://github.com/aloneguid/parquet-dotnet/blob/master/src/Parquet/Schema/ParquetSchema.cs#L153-L159) and [GetHashCode](https://github.com/aloneguid/parquet-dotnet/blob/master/src/Parquet/Schema/ParquetSchema.cs#L249-L251) are both based on the `_fields`, but [the implementation for IEquatable for Fields](https://github.com/aloneguid/parquet-dotnet/blob/master/src/Parquet/Schema/Field.cs#L139-L149) just cares about `Name` and `Path` (which will be identical for `Fields`) and `SchemaType`, which will both be `SchemaType.Struct` in the example above.

It seems like this would be easily fixable by using the `DataFields` instead since that will include [more robust equality checks](https://github.com/aloneguid/parquet-dotnet/blob/master/src/Parquet/Schema/DataField.cs#L154-L162) and include deeper `Path` checks.

### Failing test

```csharp
[Fact]
public void Schemas_different_structs_not_equal() {
    var schema1 = new ParquetSchema(new StructField("struct", new DataField<int>("id"), new DataField<string>("city")));
    var schema2 = new ParquetSchema(new StructField("struct", new DataField<int>("id"), new DataField<string>("city2")));

    Assert.NotEqual(schema1, schema2);
}
```
